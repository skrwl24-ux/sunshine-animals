# src 개발 규칙

이 디렉터리는 Sunshine Animals를 기능별로 나누어 유지보수하기 위한 개발 영역입니다.

## 호환성

기존 저장 데이터와의 호환성을 위해 다음 localStorage 키는 유지합니다.

- `saLight`
- `saDust`
- `saOwned`
- `saLang`
- `saImgCache`

기존 데이터를 초기화하거나 다른 키로 강제 이전하지 않습니다. 새 저장 필드가 필요하면 `core/storage.js`의 `migrateSave()`에서 기본값을 추가하는 방식으로 비파괴 마이그레이션합니다.

## 언어

모든 사용자 노출 문구는 한국어와 영어를 함께 작성합니다. 영어판에서 한국어가 남지 않도록 화면 문구와 동적 경고/결과 문구를 모두 검사합니다.

## 데이터

동물/퀴즈의 현재 실행 데이터는 `data/game-data.js`에 스냅샷으로 보존합니다. 동물이나 퀴즈를 추가할 때는 기존 항목과 중복을 검사한 뒤 정확한 수량만 추가합니다.

## 배포

이 브랜치는 개발용입니다. 실제 배포 서비스와 연결되어 있는지 확인되지 않은 상태에서는 배포 완료라고 말하지 않습니다.
